# 03 实施路线

## 阶段 0：骨架与决策

- 建立项目规则、目录和渐进文档。
- 审查 AstrBot 源码、许可证和扩展接口。
- 明确上游纳入方式与版本策略。

## 阶段 1：领域核心

- 已建立 `apeiria-core` 和 `anime-party` 的首批平台无关模块。
- 已使用 30 道固定题包实现 Emoji 游戏状态机。
- 已建立单元测试；人格行为样例仍待补充。
- 下一步补充领域边界、异常路径和对话行为样例，完成阶段 1 验收。

## 阶段 2：运行内核适配

- 引入固定版本 AstrBot。
- 建立薄适配插件。
- 使用假事件完成集成测试。

## 阶段 3：QQ 最小链路

- 配置 NapCat 与本机 OneBot V11。
- 限定测试群和管理员白名单。
- 验证收发、重复事件与静默控制。

## 阶段 4：数据与 AI

- 接入 SQLite 和迁移。
- 接入 Bangumi API 与缓存。
- 接入结构化题包生成和有限上下文回复。

## 阶段 5：长期运行

- Windows 启动、健康检查和退避重启。
- 一致性备份、恢复演练和升级回滚。

进入每个阶段前，先由 Owner 确认范围；不要跨阶段大规模建设。
