# Apeiria

Apeiria 是一个面向熟人 QQ 群的长期陪伴机器人项目，以艾佩理雅启发的原创人格进行自然交流，并主持动画主题轻量游戏。

项目当前处于架构对齐与骨架阶段，尚未引入运行框架或业务代码。

## 文档入口

从 [项目上下文](docs/00-CONTEXT.md) 开始，随后按任务需要渐进阅读 `docs` 中的编号文档。新窗口接续开发时，另读 [下一会话交接](docs/06-NEXT-SESSION.md)。
